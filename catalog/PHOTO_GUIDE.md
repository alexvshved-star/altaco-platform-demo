# PHOTO_GUIDE.md — фотоконвенція каталогу

Файлова система — source of truth для фото. Шляхи в JSON руками не прописуються; білд знаходить фото за `id` матеріалу.

## Конвенція

```
catalog/public/photos/{id}/
  1.jpg   ← фото 1 — показується в сітці каталогу (PHASE1_BRIEF §1)
  2.jpg   ← фото 2 — у картці
  3.jpg   ← фото 3 — у картці
  …       ← до 8 фото; нумерація суцільна (1,2,3,…)
```

- `{id}` — точний id матеріалу з `data/altaco_materials.json` (slug-чистий, латиниця).
- Формати: `.webp`, `.jpg` або `.jpeg` (білд шукає в цьому порядку).
- **Сітка каталогу** завжди показує `1.jpg` (фото 1).
- **Картка матеріалу** показує ВСІ фото: hero = фото 1, решта — мініатюри з перемиканням.
- Нема жодного файлу → генерований патерн-плейсхолдер з назвою матеріалу (НЕ стокові фото каменю).
- Рекомендований набір: 2 деталі (текстура зблизька) + 1 повний сляб.

## Рекомендації до знімків

- Сляб: фронтально, рівне освітлення, без відблисків; видно реальний край.
- Деталь: фрагмент ~40×30 см, фокус на текстурі й прожилках.
- Мінімум 1600 px по довшій стороні; без водяних знаків і колірних фільтрів.

## Alt-тексти

Генеруються з даних: «{Назва}, {фініш}, сляб {розмір}» — руками не пишуться.
